# openwebprint v0.1.0-beta.1

The first public beta of openwebprint: print, scan, and manage documents from your browser on your own computer or server. This release is intended for early testers, especially community hardware compatibility reports.

## Included

- Device discovery and manual setup with real CUPS printing and SANE scanning, plus a clearly labeled demo that needs no hardware.
- PDF, PNG, and JPEG printing with previews, copies, color, supported paper sizes, and individually supported duplex binding edges.
- Multi-page scans, feeder batches, reversible cropping, rotation, reordering, and downloadable PDFs that preserve per-page physical dimensions across mixed-resolution appends.
- Job history, retained document previews, optional local user accounts, dark mode, and responsive desktop/mobile layouts.
- Self-contained Linux and macOS packages for x64 and ARM64, including a private Node.js runtime, local launcher, and optional startup at login. SHA-256 files accompany every package.

## Install

On Linux or macOS, run as your normal user, without `sudo`:

```sh
curl -fsSL https://github.com/Florian-Cullmann/openwebprint/releases/download/v0.1.0-beta.1/install.sh -o install-openwebprint.sh
OPENWEBPRINT_VERSION=v0.1.0-beta.1 sh install-openwebprint.sh
```

This explicitly selects the beta; GitHub's `latest` endpoint does not select prereleases. The installer opens **http://127.0.0.1:3001**. Choose **Try demo** to explore, or **Start setup** with the hardware prerequisites installed. CUPS, SANE, and any device drivers are separate OS components.

See the [installation guide](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.1/docs/installation.md) for platform requirements, checksums, headless options, backups, updates, and uninstall. Source and Docker deployments are also documented in the [README](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.1/README.md).

## Known limitations

- Physical device compatibility still needs community testing. Automated tests use controlled fixtures or the explicit demo; successful discovery or backend completion does not certify physical output.
- Windows, Linux musl/Alpine, and 32-bit packages are unsupported. macOS packages require macOS 14 or newer; Linux requires glibc 2.28+ and kernel 4.18+ (x64 also requires SSE4.2).
- The UI is English. OCR, scan cancellation, individual page deletion, and access to history beyond the latest 200 jobs are not included.
- Retained document files expire after seven days or can be deleted explicitly. Back up local data and external scan folders before updates.
- Legacy scan pages with unknown DPI retain the previous A4-fit scale when edited or appended. Existing PDFs are regenerated only on those operations.
- Installation binds to loopback. With no configured users, anyone who can reach the application has full access. Add a user before granting access beyond a trusted environment.

Report device results using the [hardware compatibility template](https://github.com/Florian-Cullmann/openwebprint/issues/new?template=device.yml), including OS, device model, protocols, and what actually worked. Follow [SECURITY.md](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.1/SECURITY.md) for private vulnerability reports.
