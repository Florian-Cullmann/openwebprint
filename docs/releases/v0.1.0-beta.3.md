# openwebprint v0.1.0-beta.3

The third public beta adds German localization, scan search and ZIP downloads, browser job notifications, and guided hardware setup and diagnostics. Linux and macOS installers include the production application and a private Node.js runtime.

## Changes since beta.2

- Switch between English and German during setup, sign-in, and normal use. Dates, numbers, file sizes, and error messages follow the selected language; the preference persists in your browser and synchronizes between tabs.
- Search saved scans by title and download selected documents together as a ZIP containing their PDFs.
- Enable optional browser notifications for completed and failed jobs. Notifications require browser permission and an open application tab; they do not use a cloud push service.
- Check CUPS and SANE prerequisites during installation. On supported systems, the guided Terminal flow can install missing software or start services after explicit consent. Debian/Ubuntu uses apt-get and systemd; macOS uses system CUPS and an existing Homebrew installation for SANE.
- Run hardware diagnostics during setup or from Settings to distinguish missing tools, unavailable services, and discovery problems. Software readiness does not certify a physical device.
- Show the current scan area and estimated pixel count when the driver exposes writable dimensions. Block combinations over the existing 80-megapixel limit before acquisition, while keeping small originals at high resolution available. Unexpected oversized output reports an actionable error and preserves previously saved pages after failed appends.
- Refresh the README, screenshots, and usage and self-hosting guides.

## Install

On Linux or macOS, run as your normal user, without `sudo`:

```sh
curl -fsSL https://github.com/Florian-Cullmann/openwebprint/releases/download/v0.1.0-beta.3/install.sh -o install-openwebprint.sh
OPENWEBPRINT_VERSION=v0.1.0-beta.3 sh install-openwebprint.sh
```

This explicitly selects the beta; GitHub's `latest` endpoint does not select prereleases. The installer chooses your OS/CPU package, checks its SHA-256 checksum, creates a launcher and login startup entry, and opens **http://127.0.0.1:3001**. Choose **Try demo** to explore or **Start setup** to connect your devices. No system Node.js, npm, Git, or Docker is required. CUPS, SANE, and device drivers remain separate OS components; the guided flow explains supported changes and asks for consent before making them.

Before upgrading, stop openwebprint and back up `data/`, `config.json`, and any external scan folders. Running the installer again preserves configuration and documents; database migrations mean reverting application files alone is not a supported rollback.

See the [installation guide](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.3/docs/installation.md) for requirements, updates, backups, logs, and uninstall. Source and Docker deployments are documented in the [README](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.3/README.md).

## Known limitations

- This remains a beta. Automated application and installer tests do not certify physical printer/scanner compatibility; community device reports are welcome.
- Windows, Linux musl/Alpine, and 32-bit packages are unsupported. macOS requires version 14 or newer; Linux requires glibc 2.28+ and kernel 4.18+ (x64 also requires SSE4.2).
- OCR is not included. Scanning on macOS requires SANE backends; compatible devices depend on those backends. Homebrew is never installed automatically, and vendor drivers may still require manual setup.
- Scan-area estimates are available only when SANE exposes complete writable dimensions in millimetres. Unknown geometry remains available with a warning; actual output is still bounded to 80 megapixels per page. Cropping after scanning does not reduce acquisition size.
- Retained documents expire after the configured period. Extending retention cannot restore already deleted files. External scan folders need their own backups.
- Legacy scan pages with unknown DPI retain the previous A4-fit scale when edited or appended.
- Installation binds to loopback. With no configured users, anyone who can reach the application has full access. Add a user before granting access beyond a trusted environment.

Report device results using the [hardware compatibility template](https://github.com/Florian-Cullmann/openwebprint/issues/new?template=device.yml). Follow [SECURITY.md](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.3/SECURITY.md) for private vulnerability reports.
