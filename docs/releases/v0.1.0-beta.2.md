# openwebprint v0.1.0-beta.2

The second public beta improves printing saved documents, scan editing and recovery, and access to older jobs. Linux and macOS installers include the production application and a private Node.js runtime.

## Changes since beta.1

- Print a saved scan or retained document directly, with current printer options. Select custom page ranges and odd/even pages before submission.
- Zoom and pan document previews on desktop and mobile; fit the full page again with one action.
- Cancel active scans, remove individual scanned pages while keeping at least one, and choose scanner-supported resolutions and color modes per paper source.
- Recover complete pages from a failed scan batch after reviewing them. Failed follow-up scans preserve the previously saved document.
- Browse older jobs and scans with pagination, and switch the scan gallery between grid and list views.
- Configure separate scan and print document retention periods under Settings → General, from 1 to 3650 days. The default remains seven days.
- Load bounded, cached scan thumbnails for faster galleries and editors while preserving original image resolution for edits and PDF exports.
- Respect printer-supported color modes and improve cancellation/deletion consistency for print jobs.
- Publish installer controller state atomically to avoid partially written startup state.

## Install

On Linux or macOS, run as your normal user, without `sudo`:

```sh
curl -fsSL https://github.com/Florian-Cullmann/openwebprint/releases/download/v0.1.0-beta.2/install.sh -o install-openwebprint.sh
OPENWEBPRINT_VERSION=v0.1.0-beta.2 sh install-openwebprint.sh
```

This explicitly selects the beta; GitHub's `latest` endpoint does not select prereleases. The installer chooses your OS/CPU package, checks its SHA-256 checksum, creates a launcher and login startup entry, and opens **http://127.0.0.1:3001**. Choose **Try demo** to explore or **Start setup** to connect your devices. No system Node.js, npm, Git, or Docker is required. CUPS, SANE, and device drivers are separate OS components.

Before upgrading, stop openwebprint and back up `data/`, `config.json`, and any external scan folders. Running the installer again preserves configuration and documents; database migrations mean reverting application files alone is not a supported rollback.

See the [installation guide](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.2/docs/installation.md) for requirements, updates, backups, logs, and uninstall. Source and Docker deployments are documented in the [README](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.2/README.md).

## Known limitations

- This remains a beta. Automated application and installer tests do not certify physical printer/scanner compatibility; community device reports are welcome.
- Windows, Linux musl/Alpine, and 32-bit packages are unsupported. macOS requires version 14 or newer; Linux requires glibc 2.28+ and kernel 4.18+ (x64 also requires SSE4.2).
- The UI is English and OCR is not included. Scanning on macOS requires separately installed SANE backends; compatible devices depend on those backends.
- Retained documents expire after the configured period. Extending retention cannot restore already deleted files. External scan folders need their own backups.
- Legacy scan pages with unknown DPI retain the previous A4-fit scale when edited or appended.
- Installation binds to loopback. With no configured users, anyone who can reach the application has full access. Add a user before granting access beyond a trusted environment.

Report device results using the [hardware compatibility template](https://github.com/Florian-Cullmann/openwebprint/issues/new?template=device.yml). Follow [SECURITY.md](https://github.com/Florian-Cullmann/openwebprint/blob/v0.1.0-beta.2/SECURITY.md) for private vulnerability reports.
